Einmal pro Gerät verbinden, dann kann es losgehen.

Wie bekomme ich einen Schlüssel?
  1. Öffne github.com/settings/personal-access-tokens/new.
  2. Name: „Karaoke“, Ablauf: z. B. 1 Jahr.
  3. Repository access: Only select repositories → karaoke-studio.
  4. Permissions → Repository: Actions und Contents auf „Read and write“.
  5. „Generate token“ tippen, den Schlüssel kopieren und hier einfügen.

Der Schlüssel bleibt nur auf diesem Gerät gespeichert.
